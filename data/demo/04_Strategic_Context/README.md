# Mizan strategic context

Companion inputs for the canonical enriched executive demonstration.

- `01_Group_Strategy`: board strategy and targets.
- `02_BU_Strategies`: business-unit strategies.
- `03_Market_Reports`: market background.
- `04_Time_Series`: dated quantitative context.
- `05_Briefings`: dated executive briefings.

Use the PDFs and workbooks for portfolio facts, financial values, targets and conventions. The prior README described a different portfolio and has been superseded. This guide deliberately does not restate numeric facts that can drift from those source files.

These are synthetic, historical demo inputs. Source dates are not today's refresh time. Treat strategy updates as versioned inputs requiring validation and approval. A README is navigation/evaluator material, not business evidence. Product requirements are maintained only in `docs/requirements.md` at the repository root.
